Générer un code de suivi

Cette page n'est pas dans le menu du site et n'est pas destinée aux clients.

Ne partage jamais le lien de cette page (admin-suivi.html) à un client — seulement le code ou le lien qu'elle génère, une fois rempli. N'importe qui avec ce lien admin pourrait générer de faux codes.

Envoie le code seul, ou directement le lien complet (le client n'a alors rien à coller) — les deux sur WhatsApp comme d'habitude.
